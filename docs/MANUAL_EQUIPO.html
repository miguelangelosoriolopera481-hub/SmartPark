1. Información General del Proyecto

1.1 ¿Qué es SmartPark Pro?

SmartPark Pro es una plataforma SaaS multi-empresa para la gestión inteligente de parqueaderos. Permite que múltiples empresas (parqueaderos) operen en el mismo sistema, cada una con sus datos completamente aislados, tarifas propias, usuarios independientes y estadísticas separadas.

Analogía simple: Es como Shopify o Uber, pero para parqueaderos. Cada empresa que se registra tiene su propio "mini-sistema" pero todos comparten la misma infraestructura del servidor.

2.2 Proceso de Instalación paso a paso

Arrancar XAMPP
  1. Abrir XAMPP Control Panel (clic derecho → Ejecutar como Administrador)
  2. Clic en Start junto a Apache
  3. Clic en Start junto a MySQL
  4. Esperar a que ambos botones se pongan VERDES
Si MySQL no arranca, verificar que no haya otro MySQL corriendo. Ejecutar en PowerShell como admin: netstat -ano | findstr :3306
Instalar dependencias con Composer

Abrir terminal (PowerShell o CMD) y ejecutar:

cd C:\xampp\htdocs\sistema2
composer install

Esto descarga las librerías: PHPMailer, Endroid QR Code, Bacon QR Code.

Si dice "composer no se reconoce", hay que instalar Composer primero desde getcomposer.org
Crear archivo .env

Copiar el archivo de ejemplo:

Copy-Item .env.example .env

Editar el .env con el Bloc de Notas y verificar que tenga:

DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=smartpark
DB_USER=root
DB_PASS=
DB_CHARSET=utf8mb4
APP_URL=http://localhost/sistema2
APP_CRYPTO_KEY=XXXXXXXXXXXX
Generar APP_CRYPTO_KEY

Ejecutar en la terminal:

php -r "echo base64_encode(random_bytes(32));"

Copiar el resultado y pegarlo en el .env en la línea APP_CRYPTO_KEY=.

CRÍTICO: Guardar esta clave en un lugar seguro. Si se pierde, no podrás descifrar las API keys guardadas.
Crear la base de datos
  1. Abrir http://localhost/phpmyadmin
  2. Clic en Nueva (panel izquierdo)
  3. Nombre: smartpark
  4. Cotejamiento: utf8mb4_general_ci
  5. Clic en Crear
Importar el dump SQL
  1. Seleccionar la base smartpark en el panel izquierdo
  2. Pestaña Importar
  3. Clic en Seleccionar archivo
  4. Subir el archivo smartpark.sql
  5. Clic en Continuar (abajo)
  6. Esperar a que diga "La importación se ha realizado correctamente"
Verificar la instalación

Abrir en el navegador:

http://localhost/sistema2/

Debe cargar la página principal con el logo animado de SmartPark.

Luego probar el login:

http://localhost/sistema2/login_developer.php
Usuario: developer
Contraseña: Dev2026!

3.7 Cómo resetear una contraseña olvidada

Opción A — Desde la terminal (recomendado)

Generar el hash 
php -r "echo password_hash('NuevaClave123', PASSWORD_BCRYPT, ['cost' => 12]);"

Copiar el resultado (empieza con $2y$12$)

Actualizar en la base de datos

En phpMyAdmin → SQL:

UPDATE user SET password = 'PEGA_EL_HASH_AQUI' WHERE username = 'admin';

Debe decir "1 fila afectada"

Probar el login

Ir a login_empresa.php con la nueva contraseña.

Opción B — Script automático

$hash = & "C:\xampp\php\php.exe" -r "echo password_hash('NuevaClave123', PASSWORD_BCRYPT, ['cost' => 12]);"
& "C:\xampp\mysql\bin\mysql.exe" -u root -e "USE smartpark; UPDATE user SET password = '$hash' WHERE username = 'admin';"

4.3 Reglas de desarrollo

REGLA #1 — Multi-tenant estricto: TODAS las queries deben filtrar por empresa_id. Excepción: cuando el rol es developer.
REGLA #2 — CSRF obligatorio: Todo formulario POST debe tener <?= csrf_field() ?>.
REGLA #3 — Sesiones y roles: Siempre validar el rol con require_role() o require_role_empresa().
REGLA #4 — Sin BOM: Los archivos PHP deben guardarse sin BOM. Verificar con [System.IO.File]::ReadAllBytes().
REGLA #5 — PDO preparado: NUNCA concatenar variables en SQL. Usar prepare() y execute().
